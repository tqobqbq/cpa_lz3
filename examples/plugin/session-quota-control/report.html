统计口径与等待时间说明

同一请求计数一次，Token 与上游执行耗时累计全部重试。输入包含缓存读取，输出包含推理，这些子项不重复计入总 Token。5h 是额度窗口；节流计划是选定 Credential 后确定的等待时间，实际等待可能因取消而缩短。进行中展示已记录的等待，请求结束后仍缺少计时的部分显示为未知。总耗时包含等待、调度和重试；执行耗时不含此前等待。上游是请求去向的 Provider / Credential，下游是使用 API Key 请求本服务的客户端。来源列展示明文 API Key、服务端解析的 IP 和下游原始 User-Agent。User-Agent 筛选支持不区分大小写的部分匹配；历史未采集的值不会补推。TPS（不含首字）= 输出 Token ÷（上游执行耗时 − 首字耗时）；TPS（含首字）= 输出 Token ÷ 上游执行耗时。两者均不含调用前的调度和等待，先累加有效成功调用的输出和对应时长再相除。缺少首字计时则不推算不含首字 TPS。缓存率 = 缓存读取 Token ÷ 总输入 Token；汇总按 Token 加权。速度显示配置规则处理后的最终出站档位；Fast 兼容 priority，Ultra-fast 对应 ultrafast。过滤 service_tier 后记为 Auto，由上游自动选择档位；客户端原始值和上游响应值分别保留在详情中。计价优先使用可确认的响应档位。Codex OAuth 的响应 default/auto 视为未确认，此时按最终出站档位估价。历史未采集出站档位的记录会明确标注，估价沿用客户端档位并注明来源；估价不代表套餐扣费。历史未记录或 Auto 未确认时使用 Standard 基准并注明。Effort 不直接改变单价。费用“待定”表示有调用因缺少匹配模型或速度档位单价、适用缓存单价或完整用量而未估价；已显示的金额仅包含能估价的部分，不代表待定调用免费。失败或重试缺少用量时也可能待定。
